# F7 — Doctor de la instancia

## Objetivo

Contrastar toda la declaración contra los procesos reales.

## Precondiciones

F6 verde; acreditación realizada por cada actor. Identidad adjudicada en el
clon. El doctor se ejecuta desde ESE árbol, no desde el paquete.

## Pasos

<!-- terminal: instalador -->
```bash
PKG=/srv/fabrica/talent-factory
CLON="$(sed -n 's/^clon=//p' "$PKG/instalacion/estado/contexto.conf")"
H="$(sed -n 's/^home=//p' "$PKG/instalacion/estado/contexto.conf")"
R="$(sed -n 's/^respuestas=//p' "$PKG/instalacion/estado/contexto.conf")"
PROYECTO="$(sed -n 's/^proyecto=//p' "$R")"
export TA_BUS="$H/$PROYECTO/bus" TA_BUS_LOCK="$H/$PROYECTO/bus.lock"
export TA_BUS_STATE_DIR="$H/.local/state/talent-ceo"
export TF_MANIFEST="$PKG/manifiestos/$PROYECTO.conf" TCO_TF_MANIFEST="$PKG/manifiestos/$PROYECTO.conf"
export TA_PERFIL="$CLON/manifiestos/$PROYECTO.perfil.tsv"
S="$CLON/.claude/skills/talent-ceo/scripts"
cat "$CLON/.claude/skills/talent-ceo/references/07-doctor-y-acreditacion.md"
bash "$S/doctor.sh"
```

El check repite esa misma consulta con TA_BUS y manifiesto explícitos.
Sustituye PKG por la ruta permanente real al abrir esta terminal del instalador.
No hay skip ni variables que desactiven comprobaciones.
Un FALLA o NOVERIF cierra la puerta; rc 2 también impide avanzar.
El doctor contrasta el registro propio de cada torre y el modelo de los panes
del canal. check-F7 consume su resultado completo, sin duplicar esa lógica.
CEO conserva sus listas de supervisión; M1 declara flota vacía. estado_bus del
perfil manda para la acreditación de otros usuarios, y debe ser absoluto.

## Remediación

| Categoría literal | Acción |
|---|---|
| torre / renderer / ctx | Reabrir F5 y restaurar sesión, proceso descendiente y barra. |
| identidad / sellado / sellado-imposible | Reabrir F4 o F1 según causa; usuarios distintos y autoridad del manifiesto. |
| cron / bus / cursor | Reabrir F6; restaurar permisos y cadencia sin truncar bus ni rebobinar cursor. |
| canal / auditor | Revisar contenedor (F2), login (F3) y panes .0/.1; reabrir F5 para preparar sesiones e identidad del auditor. |
| acreditacion | El actor recupera capacidades y se reacredita con nonce nuevo en su terminal. |
| modelo | Resolver el registro bajo el usuario propietario; cambiar la torre o preparar el canal con las órdenes del skill y repetir el doctor completo. |
| menu / escalado / menu-reciente / bloqueo-sin-escalar | El actor sella ESCALA-ROL según ref 07 y espera la autoridad correspondiente. |
| NOVERIF | Restaurar sudoers exacto y legibilidad; no tratar falta de consulta como ausencia comprobada. |
| doctor rojo | Resolver las categorías impresas por el doctor; no omitir ninguna comprobación. |
| PRECOND / rc 2 / comando no verificable | Corregir perfil único, tmux/crontab, acceso local y TA_BUS según ref 07. |
