# F0 — Comprobar la máquina y el paquete

## Objetivo

Asegurar que la máquina soporta el montaje y el ZIP está íntegro.

## Precondiciones

Cuestionario COMPLETO y contexto preparado como indica CLAUDE.md.
preparar y F0 rechazan uid 0. Nunca registrar root para un rol.
No se crea infraestructura en esta fase. Usa la versión mínima del asset
de talent-context; requisitos.env solo es el fallback.

## Pasos

Confirma Linux dedicado, herramientas y cuentas. Antes de los 85 a 105 minutos
de la batería, f0-bateria.sh y el check corren las mismas comprobaciones baratas
y se detienen en segundos si falla alguna: herramientas (todas las ausentes
de una vez, con su orden apt-get), Linux, identidad Git, versión de gh, sudo
clásico y locales. sudo-rs (Ubuntu 26.04) se rechaza: vuelve al sudo clásico
con update-alternatives, como indica EMPIEZA-AQUI.md. Se exigen en_US.utf8 y
en_GB.utf8 en locale -a; si faltan, se generan con locale-gen. El check mide la RAM y
el disco de /var/lib: <12 GiB es rojo; 12–15 GiB admite un canal; a partir
de 16 GiB, RAM/8, máximo nueve. El pool siempre es loop, sin elegir ni
formatear discos. Debe caber el tamaño declarado más 20 GiB.
Los mínimos se leen de instalacion/requisitos.env: 12 GiB de RAM, 30 GiB
libres y 20 GiB de margen además del pool. Con 80 GiB de disco y 16 GiB de
RAM caben un canal y un pool de 40 GiB. La persona puede reducir pool_gib
mediante el cuestionario (no menos de 10 GiB), conservando el margen.

```bash
bash "$PKG/instalacion/scripts/verificar-nucleo.sh" --en host
bash "$PKG/skills/skill-creator/scripts/validate-package.sh" --root "$PKG/skills" --estado distribucion
bash "$PKG/instalacion/scripts/f0-bateria.sh"
```

NUCLEO.sha256 debe venir del empaquetador; no lo regeneres para ocultar cambios.
El generador de hashes es para construir la distribución, no para acreditarla.
La batería tarda, en una máquina de 4 núcleos (Intel N100), unos 85 minutos
en Ubuntu 24.04 y unos 105 en 26.04; en máquinas rápidas tarda menos.
Puedes seguir leyendo las guías mientras termina, pero no avanzar de fase.
Este paso conserva un recibo privado con rc, fecha, PASS/FAIL/SKIP, ruta del
log y sha256 de NUCLEO.sha256.
check-F0 y estado.sh avanzar F0 comprueban ese recibo sin repetir la batería:
exigen rc 0, FAIL=0, el mismo núcleo y una antigüedad menor que 24 horas.

## Comprobación

```bash
bash "$PKG/instalacion/scripts/check-F0.sh"
```

f0-bateria.sh ejecuta la batería de distribución, incluida la suite de fases,
con la siguiente selección interna:

```bash
bash "$PKG/instalacion/scripts/f0-bateria.sh"
```

La batería fija TF_PAQUETE_ESTADO=distribucion y no hereda del entorno las
variables de credencial (las mismas que rechaza la sonda del runner), de modo
que lanzarla desde una sesión de Claude Code es seguro. Cada FAIL detiene el montaje.
El paso usa run-all-suites.sh --sin talent-channels, muestra las filas rojas
del resumen y la ruta del log. Para entregar el diagnóstico:

```bash
bash "$PKG/instalacion/scripts/recolectar.sh" F0
```

SKIP separa lo no evaluado de PASS y declara su motivo: talent-channels queda
excluida porque puede terminar procesos de agentes y su verificación de
infraestructura corresponde a F2. Sin historial git se omite la auditoría de
commits (su detector tiene fixtures propios) y el Quick Start de CEO; sin
checkout del proveedor con su pin se omiten sus patches, sin descargarlo.
Sin llm-bridge activo o unidad vllm se omiten sus comprobaciones de servicio.
SKIP-OVERLAY y SKIP-STACK declaran contratos de instancia que la distribución
neutra todavía no tiene: anexos, overlay Supabase, pre-push de producto y
PROC-M13. La omisión de tooling raíz corresponde al modelo que delega esos
gates; no acredita su ejecución. La prueba móvil positiva requiere tailnet.
El hook PreToolUse de instancia tampoco está distribuido. Otras omisiones
declaran capacidades ausentes (git, enlaces, provocar un fallo concreto o
permisos que root no puede restringir). Lee las notas exactas del resumen:
ninguna omisión acredita el comportamiento que no se evaluó. Una omisión sin
contrato declarado en la batería también es FAIL.

## Al terminar

Máquina y distribución acreditadas; todavía no hay fábrica.
